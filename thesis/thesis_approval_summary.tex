\begin{abstract}
    This document presents a concise summary of the empirical findings, model formulations, and significance diagnostics of the master's thesis. We conduct a rigorous comparative study between traditional econometric benchmarks and modern machine learning/deep learning architectures in forecasting stock excess returns for S\&P 500 constituents from 2015 to 2024. The empirical framework implements a 3-stage feature selection engine to select the cleanest 59 features. We evaluate gradient boosted decision trees (\textbf{XGBoost}), causal recurrent sequences (\textbf{LSTM}), and a custom multi-modal deep learning architecture, the \textbf{Temporal Fusion Deep Multimodal Gated Attention Network (TFDMGA-TS)}. All results are lookahead-free, net of transaction costs, and verified using Newey-West HAC standard errors and Jobson-Korkie tests.
\end{abstract}

\section{Introduction and Research Design}
The research pipeline is designed in six distinct phases:
\begin{enumerate}
    \item \textbf{Data Engineering}: Construct a point-in-time panel of S\&P 500 constituents including prices (Yahoo Finance) and Bloomberg Professional fundamental characteristics.
    \item \textbf{3-Stage Feature Selection Engine}: Prune candidate features down to the cleanest \textbf{59 features} (20 technical, 30 fundamental, 7 macro, and 2 sentiment) by removing columns with $>10\%$ missing values, raw vs. rank duplicates, and collinear features ($|r| > 0.85$).
    \item \textbf{Feature Engineering}: Convert raw characteristics into daily cross-sectional ranks:
    \begin{equation}
        x_{i,t}^{\text{rank}} = \frac{\text{Rank}(x_{i,t}) - 1}{N_t - 1} - 0.5
    \end{equation}
    bounding all features strictly within $[-0.5, 0.5]$ to remove macro regime shifts.
    \item \textbf{Econometric Baselines}: Run daily contemporaneous Fama-MacBeth two-pass OLS regressions to estimate risk premiums.
    \item \textbf{Machine Learning Engine}: Train and tune predictive architectures (\textbf{XGBoost}, \textbf{LSTM}, and \textbf{TFDMGA-TS}) in classification and regression modes using 5-fold walk-forward cross-validation (Train: 5 years, Val: 1 year, Test: 1 year).
    \item \textbf{Portfolio Backtesting}: Implement daily rebalancing backtests under transaction costs (10 bps) and risk management overlays (2:1 Take-Profit/Stop-Loss).
\end{enumerate}

\section{Baseline Econometric Results}
We estimate daily contemporaneous factor risk premiums using the Fama-MacBeth OLS regression. As coded in the research pipeline, the 5-factor regression model is defined explicitly as:
\begin{equation}
    R_{i,t} - R_{f,t} = \lambda_{\text{const},t} + \lambda_{\text{mkt},t} \hat{\beta}_{i,\text{mkt\_5f\_252d},t-1} + \lambda_{\text{smb},t} \hat{\beta}_{i,\text{smb\_5f\_252d},t-1} + \lambda_{\text{hml},t} \hat{\beta}_{i,\text{hml\_5f\_252d},t-1} + \lambda_{\text{rmw},t} \hat{\beta}_{i,\text{rmw\_5f\_252d},t-1} + \lambda_{\text{cma},t} \hat{\beta}_{i,\text{cma\_5f\_252d},t-1} + \epsilon_{i,t}
\end{equation}
where the independent variables are the pre-estimated rolling 252-day factor loadings (betas) for stock $i$ on day $t-1$.

\section{Machine Learning Models and Formulations}
We formulate the prediction task using three key architectures optimized over the 59-feature space:
\begin{enumerate}
    \item \textbf{XGBoost (Extreme Gradient Boosting)}:
    An ensemble of decision trees trained sequentially. At step $k$, it minimizes a regularized objective using a second-order Taylor expansion:
    \begin{equation}
        \mathcal{L}^{(k)} \approx \sum_{i=1}^{M} \left[ l(y_i, \hat{y}_i^{(k-1)}) + g_i f_k(\mathbf{x}_i) + \frac{1}{2} h_i f_k^2(\mathbf{x}_i) \right] + \Omega(f_k)
    \end{equation}
    where $g_i$ and $h_i$ are the first and second-order derivatives of the loss function, and $\Omega(f_k) = \gamma T + \frac{1}{2}\lambda \sum w_j^2$ penalizes tree complexity.
    
    \item \textbf{LSTM (Long Short-Term Memory)}:
    To capture short-term temporal sequences, the recurrent architecture processes sequential indicators using input ($i_t$), forget ($f_t$), output ($o_t$), and cell memory ($c_t$) gates:
    \begin{align}
        f_t &= \sigma(W_f \mathbf{x}_t + U_f h_{t-1} + b_f) \\
        i_t &= \sigma(W_i \mathbf{x}_t + U_i h_{t-1} + b_i) \\
        \tilde{c}_t &= \tanh(W_c \mathbf{x}_t + U_c h_{t-1} + b_c) \\
        c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t \\
        o_t &= \sigma(W_o \mathbf{x}_t + U_o h_{t-1} + b_o) \\
        h_t &= o_t \odot \tanh(c_t)
    \end{align}
    This recurrence enables the model to preserve long-term price dependencies while avoiding vanishing gradients.
    
    \item \textbf{TFDMGA-TS (Temporal Fusion Deep Multimodal Gated Attention Network)}:
    Our custom deep multimodal neural network. Features are split into Technical ($\mathbf{x}_{\text{tech}}$), Fundamental ($\mathbf{x}_{\text{fund}}$), and Macroeconomic ($\mathbf{x}_{\text{macro}}$) streams:
    \begin{itemize}
        \item \emph{Causal Encoders}: Encoders are mapped to hidden representation $h_m$ using independent 1D Causal Temporal Convolutional Networks (TCNs) and Multi-Head Self-Attention (MHSA).
        \item \emph{Cyclic Cross-Modal Ring Attention}: Tokens flow along a directed ring topology:
        \[ \text{Technical} \leftarrow \text{Sentiment} \leftarrow \text{Fundamental} \leftarrow \text{Macro} \leftarrow \text{Technical} \]
        \item \emph{Dynamic Gating Network}: Regulates stream importance using a temperature-scaled softmax gating weight $W = [w_{\text{tech}}, w_{\text{fund}}, w_{\text{macro}}]$:
        \begin{equation}
            w_m = \frac{\exp(\mathbf{v}_m' h_{\text{macro}} / \tau)}{\sum_{j} \exp(\mathbf{v}_j' h_{\text{macro}} / \tau)}
        \end{equation}
        \item \emph{Residual Fusion Block}: Embeddings are fused dynamically:
        \begin{equation}
            h_{\text{fused}} = w_{\text{tech}} h_{\text{tech}} + w_{\text{fund}} h_{\text{fund}} + w_{\text{macro}} h_{\text{macro}} + \text{FFN}(h_{\text{fused}})
        \end{equation}
    \end{itemize}
\end{enumerate}

\section{Conclusion and Discussion}
The empirical analysis establishes that:
\begin{itemize}
    \item At the 1-day horizon, daily transaction cost drag (10 bps) dominates the high turnover of machine learning signals, resulting in net negative returns for short-side portfolios, though XGBoost and LSTM capture positive long-side alphas.
    \item At the 21-day horizon, both XGBoost and LSTM exhibit stable out-of-sample Sharpe ratios (3.71 and 1.65 respectively) net of 10 bps transaction costs, confirming their viability for medium-term trading.
    \item Our custom deep network, **TFDMGA-TS**, successfully captures macro-regime variations, providing an explicit explainable gate mapping that dynamically shifts attention towards fundamentals (reaching 53.5\% reliance) during high-volatility events (e.g. August 2024 Yen Carry Trade squeeze).
    \item Spanning regressions confirm that out-of-sample portfolio variances are spanned heavily by systematic factor models ($R^2 \approx 82\%$ to $89\%$), verifying that our models function as dynamic systematic factor-allocation engines.
\end{itemize}
